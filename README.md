# Science Sims

Interactive science simulations for students, built as single self-contained HTML files. Each simulation lives in its own folder as `index.html` and runs in any modern browser with no login or install.

| Simulation | Folder |
| --- | --- |
| Circulation Lab: circulatory system, blood sampling, microscope, exercise | `circulatory-system/` |
| Roller Coaster Energy Lab: gravitational, kinetic and thermal energy, loop and hill challenges | `roller-coaster/` |
| Spring Damping: Hooke's law, simple harmonic motion, damping, live displacement–time graph (old `spring-lab/` link redirects here) | `spring-damping/` |
| Hooke's Law / Simple Harmonic Motion Virtual Lab: virtual version of the in-class spring lab (stretch and period data) | `hookes-law-shm-lab/` |
| Meadow Food Chain: producers and consumers, population changes, disease, energy pyramid | `food-chain/` |
